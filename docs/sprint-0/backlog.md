# Product Backlog (Initial)

## User Stories

| ID | User Story | Priority | Estimate (SP) |
|---|---|---|---|
| US-01 | As a developer, I want a minimal Express service so that I have a deployable web API foundation. | High | 3 |
| US-02 | As a developer, I want unit/integration tests so that regressions are caught before deployment. | High | 5 |
| US-03 | As a DevOps engineer, I want a Docker image build process so that deployments are environment-consistent. | High | 3 |
| US-04 | As a DevOps engineer, I want a Jenkins pipeline (checkout, build, test, image, push, deploy) so that delivery is automated. | High | 8 |
| US-05 | As an operator, I want deployment to EC2 over SSH so that the latest release is reachable via public IP/DNS. | High | 5 |
| US-06 | As an operator, I want basic monitoring/logging endpoints so that I can verify runtime health quickly. | Medium | 3 |
| US-07 | As a maintainer, I want a clear runbook and evidence artifacts so that anyone can reproduce and assess the pipeline. | Medium | 3 |
