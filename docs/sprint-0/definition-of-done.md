# Definition of Done (DoD)

A backlog item is considered done only when:

1. Code is committed to a feature branch and merged via pull request into sprint/main branch.
2. Acceptance criteria for the user story are fully met.
3. Automated tests are added/updated and passing in local and CI runs.
4. Pipeline changes (if relevant) are validated with a successful Jenkins run.
5. Deployment impact is documented in sprint review notes.
6. Documentation is updated (runbook, backlog traceability, or evidence logs).
7. No critical lint/test/build failures remain open.
